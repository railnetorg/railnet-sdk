# Query

A STEAM query, the unit of work every deposit and redeem travels as. Its id is
[`toQueryId`](/utilities/queryIdentity#toqueryid) of the struct.

## Import

```ts twoslash
import type { Query } from '@railnetorg/railnet-sdk'
```

## Definition

```ts
type Query = {
  owner: Address
  receiver: Address
  input: Asset
  output: Asset
  mode: QueryMode
  salt: Hex
  data: Hex
}
```

## Properties

### owner

- **Type:** `Address`

The conduit the query belongs to.

### receiver

- **Type:** `Address`

Who the output is routed to.

### input

- **Type:** [`Asset`](/types/Asset)

### output

- **Type:** [`Asset`](/types/Asset)

The minimum the query must produce. On a deposit it names the vehicle and carries `minOutput`.

### mode

- **Type:** [`QueryMode`](/types/Enums#querymode)

### salt

- **Type:** `Hex`

The derived query salt, [`toQuerySalt`](/utilities/queryIdentity#toquerysalt) of the sender and
the raw salt.

### data

- **Type:** `Hex`

Vehicle-specific payload. `0x` from the conduit builders.
