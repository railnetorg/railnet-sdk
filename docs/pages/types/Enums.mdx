# Enums

The protocol-wide enums, shipped from the package root. Vehicles, the sector accounting engine and
the estimators read the same values.

## Import

```ts twoslash
import { AllowlistMode, EstimationType, QueryMode, QueryState } from '@railnetorg/railnet-sdk'
```

## QueryMode

Direction of a STEAM query.

```ts
enum QueryMode {
  DEPOSIT = 0,
  REDEEM = 1,
}
```

### DEPOSIT

- **Value:** `0`

### REDEEM

- **Value:** `1`

## QueryState

The state of a query in the STEAM state machine. `SETTLED` and `REJECTED` are terminal; a query in
either never transitions again.

```ts
enum QueryState {
  EMPTY = 0,
  PROCESSING = 1,
  PAUSED = 2,
  UNLOCKING = 3,
  RECOVERING = 4,
  REJECTED = 5,
  SETTLED = 6,
}
```

### EMPTY

- **Value:** `0`

No query exists for this identifier.

### PROCESSING

- **Value:** `1`

### PAUSED

- **Value:** `2`

The query is paused, waiting for an external condition.

### UNLOCKING

- **Value:** `3`

The query is ready to be settled.

### RECOVERING

- **Value:** `4`

### REJECTED

- **Value:** `5`

### SETTLED

- **Value:** `6`

## EstimationType

The direction of an estimate.

```ts
enum EstimationType {
  INPUT = 0,
  OUTPUT = 1,
}
```

### INPUT

- **Value:** `0`

Estimate the required input for a desired output.

### OUTPUT

- **Value:** `1`

Estimate the output for a given input.

## AllowlistMode

Which operations an AccountList gates with its allow-list. Sanctions and the block-list apply in every mode. Redeem consults sanctions alone.

```ts
enum AllowlistMode {
  OPEN = 0,
  REGULAR = 1,
  STRICT = 2,
}
```

### OPEN

- **Value:** `0`

The allow-list is ignored. Anyone not blocked or sanctioned may deposit and transfer.

### REGULAR

- **Value:** `1`

The allow-list gates deposits. Transfers stay open to non-blocked parties.

### STRICT

- **Value:** `2`

The allow-list gates deposits and transfers. Both sides of a transfer must be listed.
