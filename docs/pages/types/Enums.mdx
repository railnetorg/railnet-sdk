# Enums

The protocol-wide enums, shipped from the package root. They are not conduit-specific: vehicles,
the sector accounting engine and the estimators read the same values.

## Import

```ts
import { QueryMode, QueryState, EstimationType } from '@railnetorg/railnet-sdk'
```

## QueryMode

Direction of a STEAM query.

```ts
enum QueryMode {
  DEPOSIT = 0,
  REDEEM = 1,
}
```

### DEPOSIT

- **Value:** `0`

Deposit mode.

### REDEEM

- **Value:** `1`

Redeem mode.

## QueryState

Represents the state of a query within the STEAM state machine.

```ts
enum QueryState {
  EMPTY = 0,
  PROCESSING = 1,
  PAUSED = 2,
  UNLOCKING = 3,
  RECOVERING = 4,
  REJECTED = 5,
  SETTLED = 6,
}
```

### EMPTY

- **Value:** `0`

No query exists for this identifier.

### PROCESSING

- **Value:** `1`

The query is being processed.

### PAUSED

- **Value:** `2`

The query is paused, waiting for an external condition.

### UNLOCKING

- **Value:** `3`

The query is ready to be settled.

### RECOVERING

- **Value:** `4`

The query is in a recovery state.

### REJECTED

- **Value:** `5`

The query was rejected.

### SETTLED

- **Value:** `6`

The query has been settled.

## EstimationType

Represents the type of estimation to perform.

```ts
enum EstimationType {
  INPUT = 0,
  OUTPUT = 1,
}
```

### INPUT

- **Value:** `0`

Estimate the required input for a desired output.

### OUTPUT

- **Value:** `1`

Estimate the output for a given input.
