# ConduitInfo

Represents general information about a conduit, including its asset, supply metrics, and configuration.

## Import

```ts twoslash
import type { ConduitInfo } from '@railnetorg/railnet-sdk'
```

## Definition

```ts
type ConduitInfo = {
  conduit: Address
  asset: Address
  totalSupply: bigint
  totalAssets: bigint
  holdings: bigint
  decimals: number
  name: string
  symbol: string
  isEnabled: boolean
}
```

## Properties

### conduit

- **Type:** `Address`

### asset

- **Type:** `Address`

### totalSupply

- **Type:** `bigint`

### totalAssets

- **Type:** `bigint`

### holdings

- **Type:** `bigint`

The total vehicle shares held by the conduit.

### decimals

- **Type:** `number`

### name

- **Type:** `string`

### symbol

- **Type:** `string`

### isEnabled

- **Type:** `boolean`

Whether the conduit is enabled for public access.
