# ConduitPosition

An account's position in a conduit, the shares held and their value in the underlying asset.

## Import

```ts twoslash
import type { ConduitPosition } from '@railnetorg/railnet-sdk'
```

## Definition

```ts
type ConduitPosition = {
  shares: bigint
  assets: bigint
  conduit: Address
  account: Address
  blockNumber: bigint
}
```

## Properties

### shares

- **Type:** `bigint`

The conduit shares held, `balanceOf` on the conduit token.

### assets

- **Type:** `bigint`

The shares' value in the underlying asset, from the conduit's `convert`. `0n` when the account holds
no shares.

### conduit

- **Type:** `Address`

### account

- **Type:** `Address`

### blockNumber

- **Type:** `bigint`

The block both reads were served at. `convert` takes the balance `balanceOf` returned, so the two
cannot be batched into one multicall; pinned to one block, a deposit landing between them cannot
report shares at one rate and assets at another. [`getConduitPosition`](/actions/getConduitPosition)
takes a `blockNumber` parameter to read a past position; this field echoes the block that was used.
