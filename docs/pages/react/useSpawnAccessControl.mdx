# useSpawnAccessControl

React mutation hook for deploying an ExternalAccessControl contract via the factory.

## Import

```ts
import { useSpawnAccessControl } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { randomSalt } from '@railnetorg/railnet-sdk'
import { useSpawnAccessControl } from '@railnetorg/railnet-sdk/react'

function Spawn() {
  const { mutateAsync, isPending } = useSpawnAccessControl()

  const handleSpawn = async () => {
    const hash = await mutateAsync({
      factory: '0x...',
      initialDefaultAdmin: '0x...',
      deploymentSalt: randomSalt(),
      account: '0x...',
    })

    // hash is the transaction hash — wait for the receipt, then extractAccessControlAddress
  }

  return (
    <button disabled={isPending} onClick={handleSpawn}>
      Deploy Access Control
    </button>
  )
}
```

## Parameters

`chainId` — chain to simulate and sign on. Defaults to the connected one.

## Returns

```ts
UseMutationResult<Hash, Error, SpawnAccessControlParameters & { account: Address }>
```

Mutation result returning the spawn transaction hash. Extract the deployed access control with
[`extractAccessControlAddress`](/utilities/receiptHelpers#extractaccesscontroladdress). Call
`mutate` or `mutateAsync` with [`prepareSpawnAccessControl`](/actions/prepareSpawnAccessControl) parameters.

The call is simulated through the transport your wagmi config declares and only the transaction reaches the wallet, so a wallet serving stale state cannot reject a call on state that has already changed.
