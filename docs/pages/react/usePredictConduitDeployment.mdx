# usePredictConduitDeployment

React hook that predicts the deployment address of a conduit.

## Import

```ts
import { usePredictConduitDeployment } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { usePredictConduitDeployment } from '@railnetorg/railnet-sdk/react'

function PredictAddress() {
  const { data: address, isLoading } = usePredictConduitDeployment({
    factory: '0x1234...',
    name: 'My Conduit',
    symbol: 'COND',
    vehicle: '0x5678...',
    initialExpectedSupply: 1000000000000000000n,
    transferEnabled: true,
    accessControl: '0x...',
    feeManager: '0x...',
    accountList: '0x...',
    ownerRegistry: '0x...',
    querySalt: '0xabc...',
    deploymentSalt: '0xdef...',
  })

  if (isLoading) return <div>Loading...</div>

  return <p>Predicted address: {address}</p>
}
```

## Returns

```ts
UseQueryResult<Address, ReadContractErrorType>
```

Returns the predicted `Address`.

The query is automatically disabled when no public client is available.

## Parameters

Same as [`predictConduitDeployment`](/actions/predictConduitDeployment) parameters.

### chainId (optional)

- **Type:** `number`
- **Default:** the connected chain

Chain to read from. The hook resolves the public client for it, so a page can read a contract on
one chain while the wallet sits on another. The query key carries the resolved chain, so two chains
never share a cache entry.

```tsx
import { base } from 'viem/chains'

const result = usePredictConduitDeployment({
  ...spawnParameters,
  chainId: base.id, // [!code focus]
})
```

### enabled (optional)

- **Type:** `boolean`
- **Default:** `true`

Whether the query should be enabled.
