# usePredictConduitDeployment

Reads the address a conduit spawn will deploy to, as a TanStack Query result.

## Import

```ts twoslash
import { usePredictConduitDeployment } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { usePredictConduitDeployment } from '@railnetorg/railnet-sdk/react'

function PredictAddress() {
  const { data: address, isLoading } = usePredictConduitDeployment({
    factory: '0x1234...',
    name: 'My Conduit',
    symbol: 'COND',
    vehicle: '0x5678...',
    initialExpectedSupply: 1000000000000000000n,
    transferEnabled: true,
    accessControl: '0x...',
    feeManager: '0x...',
    accountList: '0x...',
    ownerRegistry: '0x...',
    querySalt: '0xabc...',
    deploymentSalt: '0xdef...',
  })

  if (isLoading) return <div>Loading...</div>

  return <p>Predicted address: {address}</p>
}
```

## Returns

```ts
UseQueryResult<Address, ReadContractErrorType>
```

## Parameters

Same as [`predictConduitDeployment`](/actions/predictConduitDeployment) parameters.

### chainId (optional)

- **Type:** `number`
- **Default:** the connected chain

Chain to read from, with its own public client. The query key carries it. See [Query keys](/react/queryOptions#query-keys).

```tsx
import { base } from 'viem/chains'

const result = usePredictConduitDeployment({
  ...spawnParameters,
  chainId: base.id, // [!code focus]
})
```

### enabled (optional)

- **Type:** `boolean`
- **Default:** `true`

## Query options

[`predictConduitDeploymentQueryOptions`](/react/queryOptions) is this read as TanStack Query options, with
`predictConduitDeploymentQueryKey` and `predictConduitDeploymentQueryPrefix` for invalidation.

```ts
import { predictConduitDeploymentQueryOptions } from '@railnetorg/railnet-sdk/react'

await queryClient.prefetchQuery(predictConduitDeploymentQueryOptions(client, parameters))
```
