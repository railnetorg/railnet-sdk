# useSetScopedRolePublic

React mutation hook for making a scoped role public (callable by any address) or restricted, on the ExternalAccessControl contract.

## Import

```ts
import { useSetScopedRolePublic } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { VEHICLE_STEAM_DEPOSIT } from '@railnetorg/railnet-sdk'
import { useSetScopedRolePublic } from '@railnetorg/railnet-sdk/react'

function MakePublic() {
  const { mutate, isPending } = useSetScopedRolePublic()

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          accessControl: '0x...',
          role: VEHICLE_STEAM_DEPOSIT,
          scope: '0x...',
          isPublic: true,
          account: '0x...',
        })
      }
    >
      Make deposit public
    </button>
  )
}
```

## Parameters

`chainId` — chain to simulate and sign on. Defaults to the connected one.

## Returns

```ts
UseMutationResult<Hash, Error, SetScopedRolePublicParameters & { account: Address }>
```

Mutation result. Call `mutate` or `mutateAsync` with [`setScopedRolePublic`](/actions/setScopedRolePublic) parameters.

The call is simulated through the transport your wagmi config declares and only the transaction reaches the wallet, so a wallet serving stale state cannot reject a call on state that has already changed.
