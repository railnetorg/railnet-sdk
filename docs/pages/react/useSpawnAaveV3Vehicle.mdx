# useSpawnAaveV3Vehicle

React mutation hook for deploying an Aave V3 vehicle via the factory.

## Import

```ts
import { useSpawnAaveV3Vehicle } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { randomSalt } from '@railnetorg/railnet-sdk'
import { useSpawnAaveV3Vehicle } from '@railnetorg/railnet-sdk/react'

function Spawn() {
  const { mutateAsync, isPending } = useSpawnAaveV3Vehicle()

  const handleSpawn = async () => {
    const hash = await mutateAsync({
      factory: '0x...',
      asset: '0x...',
      poolAddressesProvider: '0x...',
      accessControl: '0x...',
      queryRegistry: '0x...',
      initialExpectedSupply: 1000000000000000000n,
      querySalt: randomSalt(),
      deploymentSalt: randomSalt(),
      account: '0x...',
    })

    // hash is the transaction hash — wait for the receipt, then extractAaveV3VehicleAddress
  }

  return (
    <button disabled={isPending} onClick={handleSpawn}>
      Deploy Aave Vehicle
    </button>
  )
}
```

## Parameters

`chainId` — chain to simulate and sign on. Defaults to the connected one.

## Returns

```ts
UseMutationResult<Hash, Error, SpawnAaveV3VehicleParameters & { account: Address }>
```

Mutation result returning the spawn transaction hash. Extract the deployed vehicle with
[`extractAaveV3VehicleAddress`](/utilities/receiptHelpers#extractaavev3vehicleaddress). Call
`mutate` or `mutateAsync` with [`spawnAaveV3Vehicle`](/actions/spawnAaveV3Vehicle) parameters.

The call is simulated through the transport your wagmi config declares and only the transaction reaches the wallet, so a wallet serving stale state cannot reject a call on state that has already changed.
