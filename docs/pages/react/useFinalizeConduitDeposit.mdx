# useFinalizeConduitDeposit

React mutation hook for finalizing a conduit deposit via the factory.

## Import

```ts
import { useFinalizeConduitDeposit } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useFinalizeConduitDeposit } from '@railnetorg/railnet-sdk/react'

function Finalize() {
  const { mutate, isPending } = useFinalizeConduitDeposit()

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          factory: '0x...',
          conduit: '0x...',
          account: '0x...',
        })
      }
    >
      Finalize Deposit
    </button>
  )
}
```

## Returns

```ts
UseMutationResult<Hash, Error, FinalizeConduitDepositParameters & { account: Address }>
```

Mutation result. Call `mutate` or `mutateAsync` with [`finalizeConduitDeposit`](/actions/finalizeConduitDeposit) parameters.
