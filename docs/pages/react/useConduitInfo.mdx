# useConduitInfo

Reads a conduit's metadata, supply and `ready()` state, as a TanStack Query result.

## Import

```ts twoslash
import { useConduitInfo } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useConduitInfo } from '@railnetorg/railnet-sdk/react'

function ConduitInfo() {
  const { data, isLoading, error } = useConduitInfo({
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
  })

  if (isLoading) return <div>Loading conduit info...</div>
  if (error) return <div>Error: {error.message}</div>

  return (
    <div>
      <p>Name: {data?.name}</p>
      <p>Symbol: {data?.symbol}</p>
      <p>Total Supply: {data?.totalSupply.toString()}</p>
      <p>Enabled: {data?.isEnabled ? 'Yes' : 'No'}</p>
    </div>
  )
}
```

## Returns

```ts
UseQueryResult<ConduitInfo, ReadContractErrorType>
```

The conduit's asset, supply, holdings, ERC-20 metadata and `isEnabled` state, as
[`ConduitInfo`](/types/ConduitInfo).

## Parameters

### conduit

- **Type:** `Address`

```tsx
const result = useConduitInfo({
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
})
```

### chainId (optional)

- **Type:** `number`
- **Default:** the connected chain

Chain to read from. See [Query keys](/react/queryOptions#query-keys).

```tsx
import { base } from 'viem/chains'

const result = useConduitInfo({
  conduit: '0x...',
  chainId: base.id, // [!code focus]
})
```

### enabled (optional)

- **Type:** `boolean`
- **Default:** `true`

```tsx
const result = useConduitInfo({
  conduit: '0x...',
  enabled: false, // [!code focus]
})
```

## Query options

[`conduitInfoQueryOptions`](/react/queryOptions) is this read as TanStack Query options, with
`conduitInfoQueryKey` and `conduitInfoQueryPrefix` for invalidation.

```ts
import { conduitInfoQueryOptions } from '@railnetorg/railnet-sdk/react'

await queryClient.prefetchQuery(conduitInfoQueryOptions(client, parameters))
```
