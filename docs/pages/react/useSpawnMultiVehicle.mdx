# useSpawnMultiVehicle

React mutation hook for deploying a new MultiVehicle ecosystem via the factory.

## Import

```ts
import { useSpawnMultiVehicle } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { randomSalt } from '@railnetorg/railnet-sdk'
import { useSpawnMultiVehicle } from '@railnetorg/railnet-sdk/react'

function Spawn() {
  const { mutateAsync, isPending } = useSpawnMultiVehicle()

  const handleSpawn = async () => {
    const hash = await mutateAsync({
      factory: '0x...',
      asset: '0x...',
      name: 'My MultiVehicle',
      symbol: 'MMV',
      accessControl: '0x...',
      queryRegistry: '0x...',
      salts: {
        multiVehicle: randomSalt(),
        queryRedeemQueue: randomSalt(),
        queueStrategyEngine: randomSalt(),
        sectorAccountingEngine: randomSalt(),
        subQueryEngine: randomSalt(),
        vehicleManager: randomSalt(),
        initialDepositQuery: randomSalt(),
      },
      account: '0x...',
    })

    // hash is the transaction hash — wait for the receipt, then extractMultiVehicleContracts
  }

  return (
    <button disabled={isPending} onClick={handleSpawn}>
      Deploy MultiVehicle
    </button>
  )
}
```

## Returns

```ts
UseMutationResult<Hash, Error, SpawnMultiVehicleParameters & { account: Address }>
```

Mutation result returning the spawn transaction hash. Extract the deployed contracts with
[`extractMultiVehicleContracts`](/utilities/receiptHelpers#extractmultivehiclecontracts). Call
`mutate` or `mutateAsync` with [`spawnMultiVehicle`](/actions/spawnMultiVehicle) parameters.
