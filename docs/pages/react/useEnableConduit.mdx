# useEnableConduit

React mutation hook for enabling public access to a conduit.

## Import

```ts
import { useEnableConduit } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useEnableConduit } from '@railnetorg/railnet-sdk/react'

function Enable() {
  const { mutate, isPending } = useEnableConduit()

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          conduit: '0x...',
          account: '0x...',
        })
      }
    >
      Enable Conduit
    </button>
  )
}
```

## Parameters

`chainId` — chain to simulate and sign on. Defaults to the connected one.

## Returns

```ts
UseMutationResult<Hash, Error, EnableConduitParameters & { account: Address }>
```

Mutation result. Call `mutate` or `mutateAsync` with [`prepareEnableConduit`](/actions/prepareEnableConduit) parameters.

The call is simulated through the transport your wagmi config declares and only the transaction reaches the wallet, so a wallet serving stale state cannot reject a call on state that has already changed.
