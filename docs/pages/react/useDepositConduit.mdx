# useDepositConduit

React mutation hook for depositing assets into a conduit.

The conduit pulls the token, so it must be approved first — a plain ERC-20 approve, which
`useWriteContract` sends. The allowance is spent by the deposit, so a later deposit of the same
size needs a new approval.

Reads go through the transport your wagmi config declares and only the transaction reaches the
wallet, so a wallet serving stale state cannot make the deposit read a spent allowance.

## Import

```ts
import { useDepositConduit } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { erc20Abi } from 'viem'
import { useReadContract, useWriteContract } from 'wagmi'
import { useDepositConduit } from '@railnetorg/railnet-sdk/react'

const conduit = '0x...'
const token = '0x...'

function Deposit({ account, amount }: { account: `0x${string}`; amount: bigint }) {
  const { data: allowance } = useReadContract({
    address: token,
    abi: erc20Abi,
    functionName: 'allowance',
    args: [account, conduit],
  })

  const approve = useWriteContract()
  const deposit = useDepositConduit()

  if (allowance !== undefined && allowance < amount) {
    return (
      <button
        type="button"
        disabled={approve.isPending}
        onClick={() =>
          approve.writeContract({
            address: token,
            abi: erc20Abi,
            functionName: 'approve',
            args: [conduit, amount],
          })
        }
      >
        {approve.isPending ? 'Approving…' : 'Approve'}
      </button>
    )
  }

  return (
    <button
      type="button"
      disabled={deposit.isPending}
      onClick={() => deposit.mutate({ conduit, token, amount, account })}
    >
      {deposit.isPending ? 'Depositing…' : 'Deposit'}
    </button>
  )
}
```

Each step is its own transaction, so you keep both hashes and can show where the flow stands. If
the deposit is rejected the approval still stands, and the next attempt skips it.

## Parameters

`chainId` — chain to read and sign on. Defaults to the connected one.

## Variables

Everything [`prepareDepositConduit`](/actions/prepareDepositConduit) takes, with two optional:

- `vehicle` — read from `conduit.getVehicle()` when omitted.
- `salt` — a random one when omitted.
- `minOutput` — a floor on the vehicle shares the deposit must produce. Derive it from
  [`useEstimateConduit`](/react/useEstimateConduit) to set a slippage floor.

## Returns

```ts
UseMutationResult<Hash, Error, DepositConduitVariables>
```

## Full control

For a single transaction built yourself, [`prepareDepositConduit`](/actions/prepareDepositConduit)
returns the call and nothing else — hand it to wagmi's `useWriteContract`.
