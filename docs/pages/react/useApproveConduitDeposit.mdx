# useApproveConduitDeposit

React mutation hook approving a conduit to pull the deposit token. A deposit reverts without it.

## Import

```ts
import { useApproveConduitDeposit } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useApproveConduitDeposit } from '@railnetorg/railnet-sdk/react'

function Approve() {
  const { mutate, isPending } = useApproveConduitDeposit()

  return (
    <button
      type="button"
      disabled={isPending}
      onClick={() =>
        mutate({
          conduit: '0x...',
          token: '0x...',
          amount: 1000000n,
          account: '0x...',
        })
      }
    >
      Approve
    </button>
  )
}
```

The allowance is spent by the deposit, so read it before each attempt rather than approving once
and assuming it holds. [`useDepositConduit`](/react/useDepositConduit) shows the pair together.

## Parameters

`chainId` — chain to sign on. Defaults to the connected one.

## Variables

- `conduit` — the conduit that will pull the token, and so the spender being approved.
- `token` — the deposit token.
- `amount` — the allowance to set.
- `account` — the owner granting it.

## Returns

```ts
UseMutationResult<Hash, Error, ApproveConduitDepositVariables>
```
