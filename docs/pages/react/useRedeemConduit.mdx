# useRedeemConduit

React mutation hook for redeeming shares from a conduit.

## Import

```ts
import { useRedeemConduit } from 'railnet-sdk/react'
```

## Usage

```tsx
import { useRedeemConduit } from 'railnet-sdk/react'

function Redeem() {
  const { mutate, isPending } = useRedeemConduit()

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          conduit: '0x...',
          shares: 500000000000000000n,
          account: '0x...',
        })
      }
    >
      Redeem
    </button>
  )
}
```

## Returns

```ts
UseMutationResult<Hash, Error, RedeemConduitParameters & { account: Address }>
```

Mutation result. Call `mutate` or `mutateAsync` with [`redeemConduit`](/actions/redeemConduit) parameters.
