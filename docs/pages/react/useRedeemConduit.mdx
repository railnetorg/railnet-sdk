# useRedeemConduit

React mutation hook for redeeming shares from a conduit.

## Import

```ts
import { useRedeemConduit } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useRedeemConduit } from '@railnetorg/railnet-sdk/react'

function Redeem() {
  const { mutate, isPending } = useRedeemConduit()

  return (
    <button
      disabled={isPending}
      onClick={() =>
        mutate({
          conduit: '0x...',
          shares: 500000000000000000n,
          account: '0x...',
        })
      }
    >
      Redeem
    </button>
  )
}
```

## Returns

```ts
UseMutationResult<Hash, Error, RedeemConduitVariables>
```

Mutation result. Call `mutate` or `mutateAsync` with [`prepareRedeemConduit`](/actions/prepareRedeemConduit)
parameters, except that `outputAsset` is read from `conduit.asset()` and `salt` defaults to a random
one when omitted.
