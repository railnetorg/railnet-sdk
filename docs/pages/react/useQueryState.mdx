# useQueryState

Reads where a query stands in its lifecycle, as a TanStack Query result.

## Import

```ts
import { useQueryState } from '@railnetorg/railnet-sdk/react'
```

## Usage

```tsx
import { useQueryState } from '@railnetorg/railnet-sdk/react'

const { data: state } = useQueryState({ vehicle, query })
```

To poll until the query settles, spread the query options into `useQuery`:

```tsx
import { QueryState } from '@railnetorg/railnet-sdk'
import { queryStateQueryOptions } from '@railnetorg/railnet-sdk/react'
import { useQuery } from '@tanstack/react-query'

const { data: state } = useQuery({
  ...queryStateQueryOptions(publicClient, { vehicle, query }),
  refetchInterval: (result) =>
    result.state.data === QueryState.SETTLED || result.state.data === QueryState.REJECTED
      ? false
      : 15_000,
})
```

## Returns

A TanStack Query result over `QueryState`, with its `queryKey` attached. See
[`getQueryState`](/actions/getQueryState).

## Parameters

Everything [`getQueryState`](/actions/getQueryState) takes, plus:

### chainId (optional)

- **Type:** `number`
- **Default:** the connected chain

### enabled (optional)

- **Type:** `boolean`
- **Default:** `true`

## Query options

[`queryStateQueryOptions`](/react/queryOptions) is this read as TanStack Query options, with
`queryStateQueryKey` and `queryStateQueryPrefix` for invalidation.
