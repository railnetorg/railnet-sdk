# The redeem queue

Two operator overrides on the queue a MultiVehicle fulfills redeem requests from. Both are on the VehicleManager.

## Import

```ts twoslash
import {
  buildFeedQueryRedeemQueueCall,
  buildRetrieveQueryRedeemQueueAssetsCall,
} from '@railnetorg/railnet-sdk'
```

## buildFeedQueryRedeemQueueCall

```ts
buildFeedQueryRedeemQueueCall({ vehicleManager })
```

Fulfills pending redeem requests out of what the multi vehicle can currently withdraw. Needs
`MULTI_VEHICLE_FEED_QUERY_REDEEM_QUEUE`.

It serves the queue below the `minSharesForAutoFulfill` threshold that auto-fulfillment requires;
[`getVehicleManagerLimits`](/actions/getVehicleManagerLimits) reads the threshold.

Reverts `NothingToFulfill` when no request is redeemable against the withdrawable balance, which
`SECTOR_AVAILABLE` supplies.

## buildRetrieveQueryRedeemQueueAssetsCall

```ts
buildRetrieveQueryRedeemQueueAssetsCall({ vehicleManager, amount: 1_000_000n })
```

Pulls assets back out of the queue and deposits them into `SECTOR_AVAILABLE`. Needs
`MULTI_VEHICLE_RETRIEVE_QUERY_REDEEM_QUEUE_ASSETS`.

No shares are minted against the deposit, so the amount raises the per-share rate for every holder.
The surplus counts as yield, and the performance fee applies to it.

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### vehicleManager

- **Type:** `Address`

The VehicleManager of the MultiVehicle, from `extractMultiVehicleContracts`.

### amount

- **Type:** `bigint`

Only on `buildRetrieveQueryRedeemQueueAssetsCall`. In the multi vehicle's asset units.
