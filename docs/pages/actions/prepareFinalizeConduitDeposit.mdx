# prepareFinalizeConduitDeposit

Finalizes a conduit deposit after the initial setup.

## Import

```ts
import { prepareFinalizeConduitDeposit } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { prepareFinalizeConduitDeposit } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...prepareFinalizeConduitDeposit({
    factory: '0x1234...',
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### factory

- **Type:** `Address`

The address of the conduit factory contract.

```ts
prepareFinalizeConduitDeposit({
  factory: '0x1234...', // [!code focus]
  conduit: '0x...',
})
```

### conduit

- **Type:** `Address`

The address of the conduit contract.

```ts
prepareFinalizeConduitDeposit({
  factory: '0x...',
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
})
```
