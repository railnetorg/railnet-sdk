# buildForceRedeemCall

Burns a holder's conduit shares and opens a redeem query paid to them, without their signature. This is how a blocked or sanctioned account is off-boarded.

It does not complete the exit. Against an async vehicle the query is still `PROCESSING` when the
transaction lands: the shares are burned, the payout has not happened. Settle it with
[`buildProcessConduitQueryCall`](/actions/buildProcessConduitQueryCall).

The account list gates both sides. `user` must be sanctioned or block-listed, and the caller needs
`CONDUIT_FORCE_REDEEM`. Check with [`getAccountListStatus`](/actions/getAccountListStatus) first.
Reverts `ForceRedeemNotAllowed` when either side fails, `ForceRedeemUnavailable` on a conduit with
no account list, `DisabledConduit` before the conduit is enabled, and `NothingToRedeem` on a zero
`amount`.

## Import

```ts twoslash
import { buildForceRedeemCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildForceRedeemCall, getAccountListStatus } from '@railnetorg/railnet-sdk'

const status = await getAccountListStatus(client, { accountList, account: user })
if (!status.isBlocked && !status.isSanctioned) return

const { request } = await simulateContract(client, {
  ...buildForceRedeemCall({
    conduit,
    user,
    amount: shares,
    outputAsset: { asset: usdc, value: 0n },
  }),
  account,
})

await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`. On chain it returns `(queryId, state)`;
read the id off the receipt with [`extractQueryIds`](/utilities/receiptHelpers).

## Parameters

### conduit

- **Type:** `Address`

The conduit holding the shares.

### user

- **Type:** `Address`

The holder being ejected, and the address the proceeds are paid to.

### amount

- **Type:** `bigint`

Conduit shares to burn from `user`. Zero reverts `NothingToRedeem`.

### outputAsset

- **Type:** [`Asset`](/types/Asset)

The asset `user` is paid in. A zero `value` disables the amount floor.
