# buildSetMaxTotalAssetsCall

Builds the `vehicleManager.setMaxTotalAssets()` call, the cap on `totalAssets()` enforced at deposit
time.

- Requires `MULTI_VEHICLE_SET_THRESHOLDS` scoped to the VehicleManager, not to the multi vehicle.

## Import

```ts twoslash
import { buildSetMaxTotalAssetsCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { buildSetMaxTotalAssetsCall } from '@railnetorg/railnet-sdk'
import { parseUnits } from 'viem'

const call = buildSetMaxTotalAssetsCall({
  vehicleManager,
  maxTotalAssets: parseUnits('10000000', 6),
})
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### vehicleManager

- **Type:** `Address`

### maxTotalAssets

- **Type:** `bigint`

In asset units. `2n ** 256n - 1n` means uncapped. Operator-driven flows that grow `totalAssets()`
without minting shares are exempt; the cap bounds deposits. A cap below the current `totalAssets()`
stops deposits and unwinds nothing. [`getVehicleManagerLimits`](/actions/getVehicleManagerLimits)
reads the current value.
