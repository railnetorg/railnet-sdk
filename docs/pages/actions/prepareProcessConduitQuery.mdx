# prepareProcessConduitQuery

Processes a query on a conduit.

## Import

```ts
import { prepareProcessConduitQuery } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { prepareProcessConduitQuery } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...prepareProcessConduitQuery({
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
    query: {
    owner: '0x...',
    receiver: '0x...',
    input: { asset: '0x...', value: 100n },
    output: { asset: '0x...', value: 100n },
    mode: ConduitMode.DEPOSIT,
    salt: '0x...',
    data: '0x',
    },
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

The address of the conduit contract.

```ts
prepareProcessConduitQuery({
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
  query: { ... },
})
```


### query

- **Type:** `Query`

The query to process — the exact `Query` struct the conduit created. For async deposits, rebuild
it from the original call's parameters with `prepareDepositConduitQuery`. Redeems cannot be
rebuilt off-chain: the input is the vehicle-share conversion of the conduit shares, which depends
on `totalSupply`/`holdings` at execution time.

#### query.owner

- **Type:** `Address`

The owner address for the query.

#### query.receiver

- **Type:** `Address`

The receiver address for the query.

#### query.input

- **Type:** `Asset`

The input assets for the query. See [`Asset`](/types/Asset).

#### query.output

- **Type:** `Asset`

The output assets for the query. See [`Asset`](/types/Asset).

#### query.mode

- **Type:** `ConduitMode`

The conduit mode for the query. See [`Enums`](/types/Enums).

#### query.salt

- **Type:** `Hex`

The salt for the query.

#### query.data

- **Type:** `Hex`

Additional data for the query.
