# buildSpawnFeeManagerCall

Deploys a FeeManager via the factory.

- Requires `FACTORY_SPAWN` on the factory's access control.
- The factory pulls no deposit.

## Import

```ts twoslash
import { buildSpawnFeeManagerCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnFeeManagerCall, getAddresses, randomSalt } from '@railnetorg/railnet-sdk'
import { mainnet } from 'viem/chains'

const { feeManagerFactory } = getAddresses(mainnet.id)

const { request } = await simulateContract(client, {
  ...buildSpawnFeeManagerCall({
    factory: feeManagerFactory,
    accessControl: '0x1234...',
    initialFees: { performanceFeeBps: 1000, managementFeeBps: 50, depositFeeBps: 0, redeemFeeBps: 0 },
    initialMaxFees: { performanceFeeBps: 2000, managementFeeBps: 200, depositFeeBps: 100, redeemFeeBps: 100 },
    initialRecipients: [{ target: '0xd2135CfB216b74109775236E36d4b433F1DF507B', shareBps: 10000 }],
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### factory

- **Type:** `Address`

### accessControl

- **Type:** `Address`

The access control that gates the fee manager's own roles.

### initialFees

- **Type:** `Fees`

The starting rates, in basis points: `{ performanceFeeBps, managementFeeBps, depositFeeBps, redeemFeeBps }`. 10000 bps = 100%.
The builder throws on a rate above its `initialMaxFees` ceiling.

### initialMaxFees

- **Type:** `Fees`

Ceilings for each rate, fixed for the life of the contract. [`buildSetFeesCall`](/actions/buildSetFeesCall)
reverts `FeeTooHigh` above them.

### initialRecipients

- **Type:** `readonly FeeRecipient[]`

The split, as `{ target, shareBps }`. Must be non-empty, sorted strictly ascending by `target`, with
no zero `shareBps`, and sum to 10000. The builder throws on a list the contract would revert with
`RecipientsNotStrictlyAscending` or `InvalidBpsValue`.

### deploymentSalt

- **Type:** `Hex`

Part of the CREATE2 address, with every other field of the call. See
[`randomSalt`](/utilities/randomSalt).
[`predictFeeManagerDeployment`](/actions/predictFeeManagerDeployment) resolves the address from
the same parameters.
