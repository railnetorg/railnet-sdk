# buildEnableConduitTransfersCall

Turns on transfers of a conduit's shares. No call turns them back off.

- Requires `CONDUIT_SET_TRANSFER_ENABLED` scoped to the conduit.
- Reverts `StateUnchanged` when transfers are already on.

`conduit.enable()` is a different call. The ConduitFactory alone sends it, once the seed deposit
settles. See [Deploying a conduit](/guides/deployingAConduit#after-the-spawn).

## Import

```ts twoslash
import { buildEnableConduitTransfersCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildEnableConduitTransfersCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildEnableConduitTransfersCall({ conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e' }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

The conduit whose shares become transferable.
