# buildDepositConduitCall

Builds the `conduit.create()` call for a DEPOSIT query.

- The conduit must be approved for `amount` first; the deposit spends the allowance. See
  [Depositing and redeeming](/guides/depositingAndRedeeming#deposit).
- [`getDepositConduitCall`](/actions/getDepositConduitCall) reads the vehicle for you and returns
  the query id.

## Import

```ts twoslash
import { buildDepositConduitCall, randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { erc20Abi } from 'viem'
import { readContract, simulateContract, waitForTransactionReceipt, writeContract } from 'viem/actions'
import { buildDepositConduitCall, conduitAbi, randomSalt } from '@railnetorg/railnet-sdk'

const conduit = '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e'
const token = '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913'
const sender = '0xd2135CfB216b74109775236E36d4b433F1DF507B'
const amount = 1_000_000n

const approveHash = await writeContract(client, {
  address: token,
  abi: erc20Abi,
  functionName: 'approve',
  args: [conduit, amount],
  account: sender,
})
await waitForTransactionReceipt(client, { hash: approveHash })

const vehicle = await readContract(client, {
  address: conduit,
  abi: conduitAbi,
  functionName: 'getVehicle',
})

const { request } = await simulateContract(client, {
  ...buildDepositConduitCall({ conduit, token, amount, sender, vehicle, salt: randomSalt() }),
  account: sender,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

The conduit to deposit into, and the spender the token must be approved for.

### token

- **Type:** `Address`

The asset being deposited.

### amount

- **Type:** `bigint`

How much of `token` to deposit, in its own decimals.

### sender

- **Type:** `Address`

The address that will send the transaction. `conduit.create()` binds the query salt to it, so any
other sender reverts `InvalidQuerySalt`. Through a Safe, a batch or a relayer, that is the contract's
address. See [The sender](/guides/depositingAndRedeeming#the-sender).

### vehicle

- **Type:** `Address`

The vehicle backing the conduit, from `conduit.getVehicle()`. It is the query's output asset; any
other reverts `InvalidOutput`.

### salt

- **Type:** `Hex`

Generate it once per deposit with [`randomSalt`](/utilities/randomSalt) and keep it for the whole
operation. See [The salt](/guides/depositingAndRedeeming#the-salt).

### receiver

- **Type:** `Address`
- **Optional.** Defaults to `sender`.

Who receives the conduit shares.

### minOutput

- **Type:** `bigint`
- **Optional.** No floor when omitted.

A floor on the deposit's output, in vehicle shares, checked at create time against the vehicle's
own estimate. Derive it from `estimateVehicle` and `applySlippage`. A floor taken from
[`estimateConduit`](/actions/estimateConduit) is in conduit shares and bounds a different quantity;
the revert is `InvalidEstimation`. See [Slippage](/guides/depositingAndRedeeming#slippage).
