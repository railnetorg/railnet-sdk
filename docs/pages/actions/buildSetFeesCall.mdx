# buildSetFeesCall

Sets the fee rates on a fee manager.

- Requires `FEE_MANAGER_SET_FEES`.
- The builder rejects a rate above its ceiling, 10000 bps for the ongoing fees and 9999 for the
  transactional ones. On chain each rate is capped by the `initialMaxFees` fixed at spawn
  (`FeeTooHigh`), and re-sending the current rates reverts `StateUnchanged`.

## Import

```ts twoslash
import { buildSetFeesCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts twoslash
import { buildSetFeesCall } from '@railnetorg/railnet-sdk'

const call = buildSetFeesCall({
  feeManager: '0x1234...',
  fees: { performanceFeeBps: 1500, managementFeeBps: 100, depositFeeBps: 0, redeemFeeBps: 0 },
})
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### feeManager

- **Type:** `Address`

### fees

- **Type:** `Fees`

The new rates in basis points: `{ performanceFeeBps, managementFeeBps, depositFeeBps, redeemFeeBps }`.
