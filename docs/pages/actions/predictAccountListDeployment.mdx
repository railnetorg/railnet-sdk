# predictAccountListDeployment

Reads the address [`buildSpawnAccountListCall`](/actions/buildSpawnAccountListCall) will deploy to
for the same parameters, a CREATE2 over every field of the call.

## Import

```ts twoslash
import { predictAccountListDeployment } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { AllowlistMode, getAddresses, predictAccountListDeployment, randomSalt } from '@railnetorg/railnet-sdk'
import { mainnet } from 'viem/chains'
import { zeroAddress } from 'viem'

const { accountListFactory } = getAddresses(mainnet.id)

const accountList = await predictAccountListDeployment(publicClient, {
  factory: accountListFactory,
  accessControl: '0x1234...',
  mode: AllowlistMode.OPEN,
  initialAllowList: [],
  initialBlockList: [],
  sanctionsEnabled: false,
  oracle: zeroAddress,
  deploymentSalt: randomSalt(),
})
```

## Returns

`Address`

## Parameters

Same as [`buildSpawnAccountListCall`](/actions/buildSpawnAccountListCall). `sanctionsEnabled` with a
zero `oracle` throws before the read.
