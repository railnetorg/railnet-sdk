# buildUnauthorizeVehicleCall

Builds the `vehicleManager.unauthorize()` call, dropping a sub-vehicle's authorization and its
configuration.

- Requires `MULTI_VEHICLE_SET_VEHICLE_AUTHORIZATION` scoped to the VehicleManager.
- Holdings stay where they are. A position left in the vehicle can no longer be dispatched to;
  [`buildMoveBetweenSectorsCall`](/actions/buildMoveBetweenSectorsCall) and
  [`buildDispatchVehicleCall`](/actions/buildDispatchVehicleCall) move it out first.

## Import

```ts twoslash
import { buildUnauthorizeVehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { buildUnauthorizeVehicleCall } from '@railnetorg/railnet-sdk'

const call = buildUnauthorizeVehicleCall({ vehicleManager, vehicle })
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### vehicleManager

- **Type:** `Address`

### vehicle

- **Type:** `Address`

The sub-vehicle to unauthorize. Re-authorizing it later needs
[`buildAuthorizeVehicleCall`](/actions/buildAuthorizeVehicleCall) and a fresh
[`buildConfigureVehicleCall`](/actions/buildConfigureVehicleCall).
