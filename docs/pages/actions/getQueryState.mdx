# getQueryState

Reads `vehicle.state(query)`.

- The read takes the full `Query` struct. For a redeem, [`extractQueries`](/utilities/receiptHelpers#extractqueries) returns it with the vehicle.
- A query the vehicle never created reads `EMPTY`.

## Import

```ts twoslash
import { getQueryState } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { extractQueries, getQueryState } from '@railnetorg/railnet-sdk'

const [{ query, vehicle }] = extractQueries(receipt, conduit, chainId)

const state = await getQueryState(publicClient, { vehicle, query })
```

## Returns

`QueryState`

- `PROCESSING` waits on the vehicle.
- `PAUSED`, `UNLOCKING` and `RECOVERING` wait on [`buildProcessConduitQueryCall`](/actions/buildProcessConduitQueryCall).
- `SETTLED` and `REJECTED` are terminal.

## Parameters

### vehicle

- **Type:** `Address`

The conduit's vehicle. For a MultiVehicle, the MultiVehicle itself.

### query

- **Type:** `Query`

### blockNumber (optional)

- **Type:** `bigint`
- **Default:** the current block

The block the read is served at, for a past state or to line it up with another read.
