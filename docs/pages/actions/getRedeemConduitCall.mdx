# getRedeemConduitCall

Reads the conduit's underlying asset and returns the redeem call with the salt its query will
carry.

- Sends nothing. See [Call builders](/actions/callBuilders).

## Import

```ts twoslash
import { getRedeemConduitCall, randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { extractQueryIds, getRedeemConduitCall, randomSalt } from '@railnetorg/railnet-sdk'

const { call, querySalt } = await getRedeemConduitCall(publicClient, {
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
  shares: position.shares,
  sender: account.address,
  salt: randomSalt(),
})

const { request } = await simulateContract(publicClient, { ...call, account })
const receipt = await waitForTransactionReceipt(publicClient, {
  hash: await writeContract(walletClient, request),
})

const [created] = extractQueryIds(receipt, conduit)
```

## Returns

```ts
type GetRedeemConduitCallReturnType = {
  call: ReturnType<typeof buildRedeemConduitCall>
  querySalt: Hex
  outputAsset: Asset
}
```

`querySalt` is `keccak256(abi.encode(sender, salt))`, the value the created query carries. There is
no `queryId` yet; the conduit assembles a redeem's query at the share ratio of the including block.
[`extractQueryIds`](/utilities/receiptHelpers#extractqueryids) reads it from the receipt.

## Parameters

Everything [`buildRedeemConduitCall`](/actions/buildRedeemConduitCall) takes, with `outputAsset`
optional. It is `conduit.asset()` with no amount floor when omitted.
