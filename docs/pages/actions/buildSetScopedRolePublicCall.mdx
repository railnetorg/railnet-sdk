# buildSetScopedRolePublicCall

Sets whether a scoped role on the ExternalAccessControl is callable by any address.

- Requires the role's admin role, held globally or scoped to `scope`. See [Managing roles](/guides/managingRoles#scoped-first).
- Reverts `DefaultAdminCannotBePublic` on `DEFAULT_ADMIN_ROLE`, and `RolePublicStatusUnchanged` when
  the status already holds.

## Import

```ts twoslash
import { buildSetScopedRolePublicCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSetScopedRolePublicCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSetScopedRolePublicCall({
    accessControl: '0x1234...',
    role: VEHICLE_STEAM_DEPOSIT,
    scope: '0x5678...',
    isPublic: true,
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### accessControl

- **Type:** `Address`

### role

- **Type:** `Hex`

### scope

- **Type:** `Address`

### isPublic

- **Type:** `boolean`

`true` makes the scoped role callable by anyone on that scope, `false` restricts it back to explicit grantees.
