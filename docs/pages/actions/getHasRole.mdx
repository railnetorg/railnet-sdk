# getHasRole

Reads whether an account may act under a role — holding it globally, or scoped to one contract.

This mirrors what the contracts check themselves: `ExternalAccessControl.hasRoleOrScopedRole` is the
function behind `AccessControlLib.gatedCheckRole` and `ungatedCheckRole`. A `true` here means the
corresponding gated call will not revert on its role check. A role marked public reads as held by
every account.

## Import

```ts
import { getHasRole, VEHICLE_STEAM_DEPOSIT } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { createPublicClient, http } from 'viem'
import { mainnet } from 'viem/chains'
import { getHasRole, VEHICLE_STEAM_DEPOSIT } from '@railnetorg/railnet-sdk'

const client = createPublicClient({ chain: mainnet, transport: http() })

const allowed = await getHasRole(client, {
  accessControl,
  role: VEHICLE_STEAM_DEPOSIT,
  scope: vehicle,
  account: subQueryEngine,
})
```

## Returns

`boolean`

## Parameters

### accessControl

- **Type:** `Address`

The ExternalAccessControl the role lives on.

### role

- **Type:** `Hex`

The role hash. The protocol's roles are exported as constants — see [Roles](/constants/roles).

### scope

- **Type:** `Address`

The contract the role is scoped to. Pass the contract that performs the gated call: a scoped grant
only counts for its own scope, so checking against the wrong one reports `false` on a grant that
does exist.

### account

- **Type:** `Address`

The account to check.
