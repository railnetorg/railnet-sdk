# getHasRole

Reads whether an account may act under a role, held globally or scoped to one contract.

A `true` means the corresponding gated call will not revert on its role check. A public role reads
as held by every account.

## Import

```ts twoslash
import { getHasRole, VEHICLE_STEAM_DEPOSIT } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { createPublicClient, http } from 'viem'
import { mainnet } from 'viem/chains'
import { getHasRole, VEHICLE_STEAM_DEPOSIT } from '@railnetorg/railnet-sdk'

const client = createPublicClient({ chain: mainnet, transport: http() })

const allowed = await getHasRole(client, {
  accessControl,
  role: VEHICLE_STEAM_DEPOSIT,
  scope: vehicle,
  account: subQueryEngine,
})
```

## Returns

`boolean`

## Parameters

### accessControl

- **Type:** `Address`

The ExternalAccessControl the role lives on.

### role

- **Type:** `Hex`

The role hash; the protocol's roles are exported as constants, see [Roles](/constants/roles).

### scope

- **Type:** `Address`

The contract that performs the gated call. A scoped grant counts for its own scope only, so the
wrong scope reports `false` on a grant that exists.

### account

- **Type:** `Address`
