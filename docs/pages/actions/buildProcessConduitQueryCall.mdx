# buildProcessConduitQueryCall

Builds the `conduit.process()` call, which advances a query's state.

- Async vehicles need it. A synchronous one settles the query in the creating transaction.
- Sent by the query's `receiver`, or by the holder of its ERC-721 once an OwnerRegistry has wrapped
  the claim. Anyone else needs `CONDUIT_PROCESS` scoped to the conduit.
- A query already `SETTLED` or `REJECTED` returns that state without advancing. One this conduit
  never created reverts `UnknownQuery`.

## Import

```ts twoslash
import { buildProcessConduitQueryCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildProcessConduitQueryCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildProcessConduitQueryCall({
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
    query: {
      owner: '0x...',
      receiver: '0x...',
      input: { asset: '0x...', value: 100n },
      output: { asset: '0x...', value: 100n },
      mode: QueryMode.DEPOSIT,
      salt: '0x...',
      data: '0x',
    },
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

```ts
buildProcessConduitQueryCall({
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
  query: { ... },
})
```

### query

- **Type:** `Query`

The exact `Query` struct the conduit created. For an async deposit, `buildDepositConduitQuery`
rebuilds it from the original parameters. A redeem's query cannot be rebuilt off chain; its input
depends on `totalSupply` and `holdings` at execution time.

#### query.owner

- **Type:** `Address`

#### query.receiver

- **Type:** `Address`

#### query.input

- **Type:** [`Asset`](/types/Asset)

#### query.output

- **Type:** [`Asset`](/types/Asset)

#### query.mode

- **Type:** [`QueryMode`](/types/Enums#querymode)

#### query.salt

- **Type:** `Hex`

#### query.data

- **Type:** `Hex`
