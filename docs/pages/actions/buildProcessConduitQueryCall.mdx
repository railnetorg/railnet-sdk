# buildProcessConduitQueryCall

Processes a query on a conduit, advancing its state. Async vehicles need it.

The authorized sender is the query's `receiver`, or — once an OwnerRegistry has wrapped the claim —
the holder of its ERC-721. Anyone else needs `CONDUIT_PROCESS` scoped to the conduit, which is what
a keeper driving settlement holds.

A query already `SETTLED` or `REJECTED` returns that state without advancing and without any
authorization check. One this conduit never created reverts `UnknownQuery`.

## Import

```ts twoslash
import { buildProcessConduitQueryCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildProcessConduitQueryCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildProcessConduitQueryCall({
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
    query: {
    owner: '0x...',
    receiver: '0x...',
    input: { asset: '0x...', value: 100n },
    output: { asset: '0x...', value: 100n },
    mode: QueryMode.DEPOSIT,
    salt: '0x...',
    data: '0x',
    },
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

```ts
buildProcessConduitQueryCall({
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
  query: { ... },
})
```

### query

- **Type:** `Query`

The query to process — the exact `Query` struct the conduit created. For async deposits, rebuild
it from the original call's parameters with `buildDepositConduitQuery`. Redeems cannot be
rebuilt off-chain: the input is the vehicle-share conversion of the conduit shares, which depends
on `totalSupply`/`holdings` at execution time.

#### query.owner

- **Type:** `Address`

#### query.receiver

- **Type:** `Address`

#### query.input

- **Type:** [`Asset`](/types/Asset)

#### query.output

- **Type:** [`Asset`](/types/Asset)

#### query.mode

- **Type:** [`QueryMode`](/types/Enums#querymode)

#### query.salt

- **Type:** `Hex`

#### query.data

- **Type:** `Hex`
