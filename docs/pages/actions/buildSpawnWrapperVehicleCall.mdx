# buildSpawnWrapperVehicleCall

Deploys a wrapper vehicle, which holds its asset and earns nothing; it gives a plain token the
STEAM interface a conduit or a multi-vehicle expects.

- Requires `FACTORY_SPAWN` on the factory's access control.
- The factory is deployed in staging only; `wrapperVehicleFactory` comes from
  [`@railnetorg/railnet-sdk/staging`](/contracts/staging).
- It takes no `initialExpectedSupply`; the seed deposit has no floor on the shares minted.
- The factory pulls the initial deposit of `asset` from the caller and burns the shares it mints.
  Approve it for at least [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first. The deposit does not come back.

## Import

```ts twoslash
import { buildSpawnWrapperVehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { erc20Abi } from 'viem'
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnWrapperVehicleCall, getInitialDepositAmount, randomSalt } from '@railnetorg/railnet-sdk'
import { getAddresses } from '@railnetorg/railnet-sdk/staging'
import { base } from 'viem/chains'

const { assetRegistry, wrapperVehicleFactory, usdc } = getAddresses(base.id)

const amount = await getInitialDepositAmount(client, { assetRegistry, asset: usdc })

await writeContract(client, {
  address: usdc,
  abi: erc20Abi,
  functionName: 'approve',
  args: [wrapperVehicleFactory, amount],
  account,
})

const { request } = await simulateContract(client, {
  ...buildSpawnWrapperVehicleCall({
    factory: wrapperVehicleFactory,
    asset: usdc,
    accessControl: '0x...',
    queryRegistry: '0x...',
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

[`extractWrapperVehicleAddress`](/utilities/receiptHelpers#extractwrappervehicleaddress) reads the deployed address from the receipt.

## Parameters

### factory

- **Type:** `Address`

The wrapper vehicle factory, from the staging entry point.

### asset

- **Type:** `Address`

The token the vehicle wraps one-for-one. Must be a contract (`InvalidWrappedAsset`) and authorized
in the AssetRegistry, or the spawn reverts `AssetNotAuthorized`.

### accessControl

- **Type:** `Address`

The ExternalAccessControl that gates the vehicle. It must have been spawned by the access control
factory this one trusts, or the call reverts `NotDeployedByFactory`.

### queryRegistry

- **Type:** `Address`

The query registry the vehicle records its queries in. Must be a contract (`InvalidQueryRegistry`).

### feeManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

Must have been spawned by the trusted FeeManager factory when set. The zero address skips the check
and leaves the vehicle without one.

### modulesManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

Same rule as `feeManager`, against the trusted ModulesManager factory.

### forbiddenAddresses (optional)

- **Type:** `Address[]`
- **Default:** `[]`

Addresses barred from interacting with the vehicle.

### querySalt

- **Type:** `Hex`

Salt for the spawn's seed deposit query. Generate it with [`randomSalt`](/utilities/randomSalt).

### deploymentSalt

- **Type:** `Hex`

Generate it with [`randomSalt`](/utilities/randomSalt). The factory folds its deployment counter in,
so the address is only known from the receipt, through
[`extractWrapperVehicleAddress`](/utilities/receiptHelpers#extractwrappervehicleaddress).
