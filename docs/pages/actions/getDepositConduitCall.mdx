# getDepositConduitCall

Reads the conduit's vehicle and returns the deposit call with the id of the query it will create.
It only reads; sending is yours.

The `queryId` is the value `QueryCreated` carries, the key that joins a transaction to an indexed
query, and it is known before the transaction is sent.

## Import

```ts twoslash
import { getDepositConduitCall, randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { getDepositConduitCall, randomSalt } from '@railnetorg/railnet-sdk'

const { call, queryId } = await getDepositConduitCall(publicClient, {
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
  token: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913',
  amount: 1_000_000n,
  sender: account.address,
  salt: randomSalt(),
})

const { request } = await simulateContract(publicClient, { ...call, account })
const hash = await writeContract(walletClient, request)

// `queryId` keys the query in your indexer, from here on
```

## Returns

```ts
type GetDepositConduitCallReturnType = {
  call: ReturnType<typeof buildDepositConduitCall>
  query: Query
  queryId: Hex
  vehicle: Address
}
```

## Parameters

Everything [`buildDepositConduitCall`](/actions/buildDepositConduitCall) takes, with `vehicle`
optional. It is read from `conduit.getVehicle()` when omitted.

`salt` stays required. See [The salt](/guides/depositingAndRedeeming#the-salt).

A redeem has no id before the transaction lands. See [`getRedeemConduitCall`](/actions/getRedeemConduitCall#returns).
