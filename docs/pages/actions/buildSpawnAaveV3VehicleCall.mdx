# buildSpawnAaveV3VehicleCall

Deploys an Aave V3 vehicle via the factory contract.

- The caller needs `FACTORY_SPAWN` on the factory's access control.
- The factory pulls the initial deposit of `asset` from the caller. Approve it for at least
  [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first.

## Import

```ts twoslash
import { buildSpawnAaveV3VehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnAaveV3VehicleCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnAaveV3VehicleCall({
    factory: '0x1234...',
    asset: '0x6B175474E89094C44Da98b954EedeAC495271d0F',
    poolAddressesProvider: '0x2f39d218133AFaB8F2B819B1066c7E434Ad94E9e',
    accessControl: '0x...',
    queryRegistry: '0x...',
    initialExpectedSupply: 1000000000000000000n,
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

[`extractAaveV3VehicleAddress`](/utilities/receiptHelpers#extractaavev3vehicleaddress) reads the deployed address from the receipt.

## Parameters

### factory

- **Type:** `Address`

### asset

- **Type:** `Address`

### poolAddressesProvider

- **Type:** `Address`

### accessControl

- **Type:** `Address`

The ExternalAccessControl that gates the vehicle. It must have been spawned by the access control
factory this one trusts, or the call reverts `NotDeployedByFactory`.

### queryRegistry

- **Type:** `Address`

The query registry the vehicle records its queries in. Must be a contract (`InvalidQueryRegistry`).

### feeManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

Must have been spawned by the trusted FeeManager factory when set. The zero address skips the check
and leaves the vehicle without one.

### modulesManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

Same rule as `feeManager`, against the trusted ModulesManager factory.

### forbiddenAddresses (optional)

- **Type:** `Address[]`
- **Default:** `[]`

### initialExpectedSupply

- **Type:** `bigint`

Floor on the shares the seed deposit must mint; zero reverts `InvalidInitialExpectedSupply`.

### querySalt

- **Type:** `Hex`

Salt for the spawn's initial query. Generate it with [`randomSalt`](/utilities/randomSalt).

### deploymentSalt

- **Type:** `Hex`

Generate it with [`randomSalt`](/utilities/randomSalt). The factory folds its deployment counter in,
so the address is only known from the receipt, through
[`extractAaveV3VehicleAddress`](/utilities/receiptHelpers#extractaavev3vehicleaddress).
