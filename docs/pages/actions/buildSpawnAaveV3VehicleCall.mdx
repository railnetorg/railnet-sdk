# buildSpawnAaveV3VehicleCall

Deploys an Aave V3 vehicle via the factory contract.

- The caller needs `FACTORY_SPAWN` on the factory's access control.
- The factory pulls the initial deposit of `asset` from the caller. Approve it for at least
  [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first.

## Import

```ts twoslash
import { buildSpawnAaveV3VehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnAaveV3VehicleCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnAaveV3VehicleCall({
    factory: '0x1234...',
    asset: '0x6B175474E89094C44Da98b954EedeAC495271d0F',
    poolAddressesProvider: '0x2f39d218133AFaB8F2B819B1066c7E434Ad94E9e',
    accessControl: '0x...',
    queryRegistry: '0x...',
    initialExpectedSupply: 1000000000000000000n,
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

:::info
Use [`extractAaveV3VehicleAddress`](/utilities/receiptHelpers#extractaavev3vehicleaddress) to extract the deployed Aave V3 vehicle address from the transaction receipt.
:::

## Parameters

### factory

- **Type:** `Address`

### asset

- **Type:** `Address`

### poolAddressesProvider

- **Type:** `Address`

### accessControl

- **Type:** `Address`

### queryRegistry

- **Type:** `Address`

### feeManager (optional)

- **Type:** `Address`

### modulesManager (optional)

- **Type:** `Address`

### forbiddenAddresses (optional)

- **Type:** `Address[]`

### initialExpectedSupply

- **Type:** `bigint`

### querySalt

- **Type:** `Hex`

Salt for the spawn's initial query. Generate it with [`randomSalt`](/utilities/randomSalt).

### deploymentSalt

- **Type:** `Hex`

Not enough on its own to predict the address: the factory folds its `deploymentCounter` into the
vehicle's generated name and symbol, so the same salt lands elsewhere at every spawn. Generate it
with [`randomSalt`](/utilities/randomSalt) and read the address back from the receipt with
[`extractAaveV3VehicleAddress`](/utilities/receiptHelpers#extractaavev3vehicleaddress).
