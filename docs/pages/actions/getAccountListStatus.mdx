# getAccountListStatus

Every verdict an [AccountList](/actions/accountListConfiguration) holds on one account, in one multicall.

A `false` here is the `CreateNotAllowed` or `NotAllowed` revert the conduit would give.

## Import

```ts twoslash
import { getAccountListStatus } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { getAccountListStatus } from '@railnetorg/railnet-sdk'

const status = await getAccountListStatus(publicClient, { accountList, account })

if (!status.canDeposit) {
  return status.isSanctioned ? refuse() : requestAllowListing()
}
```

The three raw flags come back with the verdicts, so an operator sees which one failed.

## Returns

`AccountListStatus`

```ts
type AccountListStatus = {
  canDeposit: boolean
  canRedeem: boolean
  canReceive: boolean
  isAllowListed: boolean
  isBlocked: boolean
  isSanctioned: boolean
  mode: AllowlistMode
}
```

### canDeposit

Not blocked, not sanctioned, and allow-listed under `REGULAR` or `STRICT`.

### canRedeem

Sanctions alone gate a redeem, so a blocked holder passes. See [`AllowlistMode`](/types/Enums#allowlistmode).

### canReceive

Whether the account may be the receiver of a transfer or a third-party query.

### isSanctioned

Set by the oracle, or when the oracle fails to answer. See [Sanctions screening](/actions/accountListConfiguration#sanctions-screening).

### mode

The [`AllowlistMode`](/types/Enums#allowlistmode) the list runs in, which decides whether `isAllowListed` is
consulted at all.

## Parameters

### accountList

- **Type:** `Address`

The AccountList the conduit was spawned with. It is fixed at spawn, with no setter.

### account

- **Type:** `Address`

`canTransfer` and `canForceRedeem` take a pair, so this read leaves them out;
[`getIsTransferable`](/actions/getIsTransferable) answers for a transfer.
