# prepareDepositConduit

Builds the call that deposits assets into a conduit. 
A deposit is two transactions: the conduit pulls the token, so it must be approved first, and the
allowance is spent by the deposit. The SDK does not approve on your behalf — an approval is a plain
ERC-20 call and hiding it costs you its hash.

## Import

```ts
import { prepareDepositConduit, randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { createWalletClient, erc20Abi, http } from 'viem'
import { base } from 'viem/chains'
import { readContract, simulateContract, waitForTransactionReceipt, writeContract } from 'viem/actions'
import { conduitAbi, prepareDepositConduit, randomSalt } from '@railnetorg/railnet-sdk'

const client = createWalletClient({ chain: base, transport: http() })

const conduit = '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e'
const token = '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913'
const account = '0xd2135CfB216b74109775236E36d4b433F1DF507B'
const amount = 1_000_000n

const approveHash = await writeContract(client, {
  address: token,
  abi: erc20Abi,
  functionName: 'approve',
  args: [conduit, amount],
  account,
})
await waitForTransactionReceipt(client, { hash: approveHash })

const vehicle = await readContract(client, {
  address: conduit,
  abi: conduitAbi,
  functionName: 'getVehicle',
})

const { request } = await simulateContract(client, {
  ...prepareDepositConduit({ conduit, token, amount, account, vehicle, salt: randomSalt() }),
  account,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

The conduit to deposit into, and the spender the token must be approved for.

### token

- **Type:** `Address`

The asset being deposited.

### amount

- **Type:** `bigint`

How much of `token` to deposit, in its own decimals.

### account

- **Type:** `Address`

The depositor. The query's salt is derived from it, so it must match the sender.

### vehicle

- **Type:** `Address`

The vehicle backing the conduit, read from `conduit.getVehicle()`. It names the query's output
asset, and the deposit reverts if it does not.

### salt

- **Type:** `Hex`

A per-deposit salt. Use [`randomSalt`](/utilities/randomSalt) unless you need a deterministic one.

### receiver

- **Type:** `Address`
- **Optional.** Defaults to `account`.

Who receives the conduit shares.

### minOutput

- **Type:** `bigint`
- **Optional.** No floor when omitted.

A floor on the vehicle shares the deposit must produce. Derive it from `estimateVehicle` and `applySlippage`, both exported from the package, to set a
slippage bound.

## React

[`useDepositConduit`](/react/useDepositConduit) wraps the deposit. The approval is yours to send.
