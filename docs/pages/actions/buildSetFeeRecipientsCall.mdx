# buildSetFeeRecipientsCall

Replaces the whole recipient split on a fee manager.

- Requires `FEE_MANAGER_SET_FEE_RECIPIENTS`.

## Import

```ts twoslash
import { buildSetFeeRecipientsCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts twoslash
import { buildSetFeeRecipientsCall } from '@railnetorg/railnet-sdk'

const call = buildSetFeeRecipientsCall({
  feeManager: '0x1234...',
  recipients: [
    { target: '0x1111111111111111111111111111111111111111', shareBps: 4000 },
    { target: '0x2222222222222222222222222222222222222222', shareBps: 6000 },
  ],
})
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### feeManager

- **Type:** `Address`

### recipients

- **Type:** `readonly FeeRecipient[]`

Must be non-empty, sorted strictly ascending by `target`, with no zero `target` or `shareBps`, and
sum to 10000. The builder throws on a list the contract would revert with
`RecipientsNotStrictlyAscending` or `InvalidBpsValue`.
