# buildSpawnAccessControlCall

Deploys an ExternalAccessControl via `accessControlFactory.spawn()`.

- No role gates it.

## Import

```ts twoslash
import { buildSpawnAccessControlCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnAccessControlCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnAccessControlCall({
    factory: '0x1234...',
    initialDefaultAdmin: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

[`extractAccessControlAddress`](/utilities/receiptHelpers#extractaccesscontroladdress) reads the deployed address from the receipt.

## Parameters

### factory

- **Type:** `Address`

### initialDefaultAdmin

- **Type:** `Address`

### initialDelay (optional)

- **Type:** `number`
- **Default:** `0`

Delay, in seconds, on admin role changes.

### initialRoles (optional)

- **Type:** `Array<{account: Address, role: Hex}>`
- **Default:** `[]`

### deploymentSalt

- **Type:** `Hex`

Part of the CREATE2 address, with every other field of the call. See
[`randomSalt`](/utilities/randomSalt).
