# buildSetQueuesCall

Sets deposit and redeem queues on the QueueStrategyEngine. Requires a `WalletClient`.

The caller needs `MULTI_VEHICLE_SET_QUEUES` scoped to the engine. Entries are validated on chain and rejected with `InvalidQueueEntry(index, vehicle, reason)`. Both queues need a ready vehicle whose asset matches the engine's, in a mode other than `Manual`; a deposit entry also needs it authorized with a non-zero `value`, a redeem entry a single-asset vehicle and a finite target. `threshold > value` on a finite target reverts `InvalidTarget`.

## Import

```ts
import { buildSetQueuesCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSetQueuesCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSetQueuesCall({
    queueStrategyEngine: '0x1234...',
    depositQueue: [
    {
    vehicle: '0x5678...',
    target: { value: 1000000n, threshold: 100n }
    }
    ],
    redeemQueue: [],
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### queueStrategyEngine

- **Type:** `Address`

The address of the QueueStrategyEngine contract.

### depositQueue / redeemQueue

- **Type:** `QueueEntry[]`

The new queue configuration: one `{ vehicle, target }` per sub-vehicle, in allocation order.

```ts
type QueueTarget = { value: bigint; threshold: bigint }
```

`value` is an allocation target in the sub-vehicle's share units, `threshold` a tolerance margin in
the same units that must not exceed `value` on a finite target. `2n ** 256n - 1n` (unlimited) is
accepted on the deposit queue only — an unlimited `value + threshold` on a redeem entry is
rejected.
