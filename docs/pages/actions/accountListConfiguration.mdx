# Configuring an AccountList

Every call here needs `ACCOUNT_LIST_MANAGER` on the account list's access control, and each returns a prepared call: `{ address, abi, functionName, args }`.

## Import

```ts twoslash
import {
  buildAddToAllowListCall,
  buildAddToBlockListCall,
  buildRemoveFromAllowListCall,
  buildRemoveFromBlockListCall,
  buildSetAllowlistModeCall,
  buildSetSanctionsOracleCall,
  buildToggleSanctionsCall,
} from '@railnetorg/railnet-sdk'
```

## buildSetAllowlistModeCall

```ts
buildSetAllowlistModeCall({ accountList: '0x1234...', mode: AllowlistMode.STRICT })
```

Switching mode changes which operations consult the lists; the lists themselves do not change.
Reverts `ModeUnchanged` when the mode already holds.

## The four list calls

```ts
buildAddToAllowListCall({ accountList: '0x1234...', accounts: ['0xd213...'] })
buildRemoveFromAllowListCall({ accountList: '0x1234...', accounts: ['0xd213...'] })
buildAddToBlockListCall({ accountList: '0x1234...', accounts: ['0xd213...'] })
buildRemoveFromBlockListCall({ accountList: '0x1234...', accounts: ['0xd213...'] })
```

Each takes a batch, and all four reject an empty batch, the zero address or a repeated account
before assembling the call. On chain, adding a listed account reverts `AddressAlreadyListed`,
removing an absent one `AddressNotListed`, the zero address `ZeroAddress`, and adding to the
block-list an account the allow-list holds `AddressOnOtherList`.

A blocked account keeps the right to redeem; sanctions remove it. See
[`AllowlistMode`](/types/Enums#allowlistmode). [`buildForceRedeemCall`](/actions/buildForceRedeemCall)
off-boards a blocked holder.

## Sanctions screening

```ts
buildSetSanctionsOracleCall({ accountList: '0x1234...', oracle: '0x5678...' })
buildToggleSanctionsCall({ accountList: '0x1234...', enabled: true })
```

`toggleSanctions(true)` reverts `SanctionsOracleRequired` without an oracle, and the oracle returns
to the zero address only while screening is off. Re-sending the current enabled state reverts
`SanctionsUnchanged`; setting the oracle to its current value reverts `OracleUnchanged`.

Screening fails closed. An oracle that reverts, or returns anything other than 32 bytes, marks the
account sanctioned, and a sanctioned account cannot deposit, transfer or redeem.

## Parameters

### accountList

- **Type:** `Address`

### mode

- **Type:** [`AllowlistMode`](/types/Enums#allowlistmode)

### accounts

- **Type:** `readonly Address[]`

The batch for the four list calls.

### oracle

- **Type:** `Address`

An `ISanctionsList` contract, or the zero address while screening stays off.

### enabled

- **Type:** `boolean`
