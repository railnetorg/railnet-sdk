# authorizeVehicle

Authorizes a vehicle in the VehicleRegistry. Requires a `WalletClient`.

## Import

```ts
import { authorizeVehicle } from 'railnet-sdk'
```

## Usage

```ts
import { createWalletClient, http } from 'viem'
import { base } from 'viem/chains'
import { authorizeVehicle } from 'railnet-sdk'

const walletClient = createWalletClient({
  chain: base,
  transport: http(),
})

const hash = await authorizeVehicle(walletClient, {
  vehicleRegistry: '0x1234...',
  vehicle: '0x5678...',
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})
```

## Returns

`Hash`

The transaction hash.

## Parameters

### vehicleRegistry

- **Type:** `Address`

The address of the VehicleRegistry contract.

### vehicle

- **Type:** `Address`

The address of the vehicle to authorize.

### account

- **Type:** `Address`

The address of the account executing the transaction.
