# buildFinalizeConduitDepositCall

Settles the seed deposit an asynchronous vehicle left pending after `spawn()`, and enables the conduit
once it reaches `SETTLED`.

- No role gates it. Reverts `NoPendingDeposit` when the conduit has no deposit awaiting settlement.

## Import

```ts twoslash
import { buildFinalizeConduitDepositCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildFinalizeConduitDepositCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildFinalizeConduitDepositCall({
    factory: '0x1234...',
    conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e',
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### factory

- **Type:** `Address`

```ts
buildFinalizeConduitDepositCall({
  factory: '0x1234...', // [!code focus]
  conduit: '0x...',
})
```

### conduit

- **Type:** `Address`

```ts
buildFinalizeConduitDepositCall({
  factory: '0x...',
  conduit: '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e', // [!code focus]
})
```
