# buildSpawnConduitCall

Deploys a new conduit via the factory contract.

The caller needs `CONDUIT_SPAWN` on the factory's access control, scoped to the factory. It is the
one factory that does not gate on `FACTORY_SPAWN`.

- The factory pulls the initial deposit of the vehicle's asset from the caller. Approve it for
  at least [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first.

`feeManager`, `accountList`, `ownerRegistry` and `accessControl` must each have been spawned by
the factory this one trusts for that module, or the call reverts `NotDeployedByFactory`.
`initialExpectedSupply` must be non-zero.

## Import

```ts twoslash
import { buildSpawnConduitCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnConduitCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnConduitCall({
    factory: '0x1234...',
    name: 'My Conduit',
    symbol: 'COND',
    vehicle: '0x5678...',
    initialExpectedSupply: 1000000000000000000n,
    transferEnabled: true,
    accessControl: '0x...',
    feeManager: '0x...',
    accountList: '0x...',
    ownerRegistry: '0x...',
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

:::info
Use [`extractConduitAddress`](/utilities/receiptHelpers#extractconduitaddress) to extract the deployed conduit address from the transaction receipt.
:::

## Parameters

### factory

- **Type:** `Address`

### name

- **Type:** `string`

### symbol

- **Type:** `string`

### vehicle

- **Type:** `Address`

### initialExpectedSupply

- **Type:** `bigint`

### transferEnabled

- **Type:** `boolean`

### accessControl

- **Type:** `Address`

### feeManager

- **Type:** `Address`

### accountList

- **Type:** `Address`

### ownerRegistry

- **Type:** `Address`

### initialInterceptions (optional)

- **Type:** [`Interception[]`](/types/Interception)

Optional initial reward interception routes for the conduit. Defaults to `[]`.

### querySalt

- **Type:** `Hex`

Salt for the spawn's initial query. Generate it with [`randomSalt`](/utilities/randomSalt).

### deploymentSalt

- **Type:** `Hex`

One ingredient of the deployed address: it is a CREATE2 over the proxy's init code, which carries
every module and metadata field above. Generate the salt with
[`randomSalt`](/utilities/randomSalt), keep the value, and resolve the address with
[`predictConduitDeployment`](/actions/predictConduitDeployment) using exactly the parameters you
will send.
