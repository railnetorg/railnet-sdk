# buildSpawnConduitCall

Deploys a conduit via `conduitFactory.spawn()`.

- Requires `CONDUIT_SPAWN` scoped to the factory. The other factories gate on `FACTORY_SPAWN`; this
  one does not.
- The factory pulls the initial deposit of the vehicle's asset from the caller. Approve it for at
  least [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first.
- `feeManager`, `accountList`, `ownerRegistry` and `accessControl` must each come from the factory
  this one trusts for that module, or the call reverts `NotDeployedByFactory`.
- `initialExpectedSupply` must be non-zero.
- [Deploying a conduit](/guides/deployingAConduit) gives the order.

## Import

```ts twoslash
import { buildSpawnConduitCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnConduitCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnConduitCall({
    factory: '0x1234...',
    name: 'My Conduit',
    symbol: 'COND',
    vehicle: '0x5678...',
    initialExpectedSupply: 1000000000000000000n,
    transferEnabled: true,
    accessControl: '0x...',
    feeManager: '0x...',
    accountList: '0x...',
    ownerRegistry: '0x...',
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.
[`extractConduitAddress`](/utilities/receiptHelpers#extractconduitaddress) reads the deployed
address from the receipt.

## Parameters

### factory

- **Type:** `Address`

### name

- **Type:** `string`

### symbol

- **Type:** `string`

### vehicle

- **Type:** `Address`

### initialExpectedSupply

- **Type:** `bigint`

### transferEnabled

- **Type:** `boolean`

### accessControl

- **Type:** `Address`

### feeManager

- **Type:** `Address`

### accountList

- **Type:** `Address`

### ownerRegistry

- **Type:** `Address`

### initialInterceptions (optional)

- **Type:** [`Interception[]`](/types/Interception)
- **Default:** `[]`

See [Setting interceptions](/actions/setInterceptions).

### querySalt

- **Type:** `Hex`

Salt for the spawn's initial query. Generate it with [`randomSalt`](/utilities/randomSalt).

### deploymentSalt

- **Type:** `Hex`

Part of the CREATE2 address, with every module and metadata field above. Generate it with
[`randomSalt`](/utilities/randomSalt) and keep the value.
[`predictConduitDeployment`](/actions/predictConduitDeployment) resolves the address from the same
parameters.
