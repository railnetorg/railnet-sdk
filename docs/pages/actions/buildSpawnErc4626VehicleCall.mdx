# buildSpawnErc4626VehicleCall

Deploys a vehicle that supplies into an ERC-4626 vault. The vehicle's asset is the vault's own
`asset()`.

- Requires `FACTORY_SPAWN` on the factory's access control.
- [Deploying a vehicle](/guides/deployingAVehicle) gives the order.

## Import

```ts twoslash
import { buildSpawnErc4626VehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { erc20Abi, erc4626Abi } from 'viem'
import { readContract, simulateContract, writeContract } from 'viem/actions'
import {
  buildSpawnErc4626VehicleCall,
  getAddresses,
  getInitialDepositAmount,
  randomSalt,
} from '@railnetorg/railnet-sdk'
import { mainnet } from 'viem/chains'

const { assetRegistry, erc4626VehicleFactory } = getAddresses(mainnet.id)
const vault = '0x1234...'

const asset = await readContract(client, { address: vault, abi: erc4626Abi, functionName: 'asset' })
const amount = await getInitialDepositAmount(client, { assetRegistry, asset })

await writeContract(client, {
  address: asset,
  abi: erc20Abi,
  functionName: 'approve',
  args: [erc4626VehicleFactory, amount],
  account,
})

const { request } = await simulateContract(client, {
  ...buildSpawnErc4626VehicleCall({
    factory: erc4626VehicleFactory,
    vault,
    accessControl: '0x...',
    queryRegistry: '0x...',
    initialExpectedSupply: 10n ** 18n,
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

[`extractErc4626VehicleAddress`](/utilities/receiptHelpers#extracterc4626vehicleaddress) reads the deployed address from the receipt.

## Parameters

### factory

- **Type:** `Address`

The ERC-4626 vehicle factory. Available as `erc4626VehicleFactory` from [`getAddresses`](/contracts/getAddresses).

### vault

- **Type:** `Address`

The ERC-4626 vault to wrap. It must be a contract (`InvalidVault`) whose `asset()` is one too
(`InvalidAsset`), and that asset must be authorized in the AssetRegistry; the spawn reads its
initial deposit amount and reverts `AssetNotAuthorized` when there is none.

### accessControl

- **Type:** `Address`

### queryRegistry

- **Type:** `Address`

### feeManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### modulesManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### forbiddenAddresses (optional)

- **Type:** `Address[]`
- **Default:** `[]`

Addresses barred from interacting with the vehicle.

### initialExpectedSupply

- **Type:** `bigint`

Floor on the shares the seed deposit must mint. Zero is rejected
(`InvalidInitialExpectedSupply`), and a floor the deposit does not reach reverts
`ExpectedSupplyNotReached`.

### querySalt

- **Type:** `Hex`

### deploymentSalt

- **Type:** `Hex`
