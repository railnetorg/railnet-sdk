# buildMoveBetweenSectorsCall

Builds the `sectorAccountingEngine.move()` call, which moves assets or shares between two
[sectors](/types/Sector) of a MultiVehicle.

- Requires `MULTI_VEHICLE_MOVE` scoped to the SectorAccountingEngine.

## Import

```ts twoslash
import { buildMoveBetweenSectorsCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildMoveBetweenSectorsCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildMoveBetweenSectorsCall({
    sectorAccountingEngine: '0x...',
    from: SECTOR_AVAILABLE,
    to: SECTOR_RESERVED,
    asset: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913',
    amount: 1000000n,
    operationId: '0x...',
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### sectorAccountingEngine

- **Type:** `Address`

The SectorAccountingEngine of the MultiVehicle, from `extractMultiVehicleContracts`.

### from / to

- **Type:** [`Sector`](/types/Sector)

Source and destination sectors. Use the `SECTOR_*` constants for static sectors and `vehicleSector(address)`
for a sub-vehicle's own sector.

### asset

- **Type:** `Address`

The base asset for an asset sector, the vehicle share token for a share sector.

### amount

- **Type:** `bigint`

The amount to move, or `maxUint256` for the whole source sector balance.

### operationId

- **Type:** `Hex`

A caller-supplied identifier echoed in the `Moved` event, for an indexer to join on.
