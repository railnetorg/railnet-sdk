# buildSpawnMultiVehicleCall

Deploys a multi-vehicle and its engines via `multiVehicleFactory.spawn()`.

- The caller needs `FACTORY_SPAWN` on the factory's access control.
- The factory pulls the initial deposit of `asset` from the caller. Approve it for at least
  [`getInitialDepositAmount`](/actions/getInitialDepositAmount) first.
- [Deploying a multi-vehicle](/guides/deployingAMultiVehicle) gives the order.

## Import

```ts twoslash
import { buildSpawnMultiVehicleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildSpawnMultiVehicleCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildSpawnMultiVehicleCall({
    factory: '0x1234...',
    asset: '0x6B175474E89094C44Da98b954EedeAC495271d0F',
    name: 'My MultiVehicle',
    symbol: 'MMV',
    accessControl: '0x...',
    queryRegistry: '0x...',
    salts: {
    multiVehicle: randomSalt(),
    queryRedeemQueue: randomSalt(),
    queueStrategyEngine: randomSalt(),
    sectorAccountingEngine: randomSalt(),
    subQueryEngine: randomSalt(),
    vehicleManager: randomSalt(),
    initialDepositQuery: randomSalt(),
    },
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.
[`extractMultiVehicleContracts`](/utilities/receiptHelpers#extractmultivehiclecontracts) reads the
six deployed addresses from the receipt.

## Parameters

### factory

- **Type:** `Address`

### asset

- **Type:** `Address`

### name

- **Type:** `string`

### symbol

- **Type:** `string`

### accessControl

- **Type:** `Address`

### queryRegistry

- **Type:** `Address`

### feeManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### modulesManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### forbiddenAddresses (optional)

- **Type:** `Address[]`
- **Default:** `[]`

### salts

- **Type:** `MultiVehicleSalts`

Six deployment salts, one per contract, plus `initialDepositQuery` for the seed deposit. Each proxy
is deployed before it is initialized, so its salt alone fixes its address. Generate each with
[`randomSalt`](/utilities/randomSalt) and keep them.

```ts
type MultiVehicleSalts = {
  multiVehicle: Hex
  queryRedeemQueue: Hex
  queueStrategyEngine: Hex
  sectorAccountingEngine: Hex
  subQueryEngine: Hex
  vehicleManager: Hex
  initialDepositQuery: Hex
}
```

### initialInterceptions (optional)

- **Type:** [`Interception[]`](/types/Interception)
- **Default:** `[]`

See [Setting interceptions](/actions/setInterceptions).
