# getInitialDepositAmount

Reads the initial deposit amount registered for an asset in the AssetRegistry.

- Every conduit and vehicle spawn pulls this amount from the caller. The module factories, access
  control, account list, owner registry and fee manager, pull nothing.
- The amount is registry state, not a spawn parameter. A spawn without the approval reverts
  `InsufficientAllowance`, without the balance `InsufficientAssetBalance`.

## Import

```ts twoslash
import { getInitialDepositAmount } from '@railnetorg/railnet-sdk'
```

## Usage

```ts twoslash
import { createPublicClient, http } from 'viem'
import { mainnet } from 'viem/chains'
import { getAddresses, getInitialDepositAmount } from '@railnetorg/railnet-sdk'

const publicClient = createPublicClient({
  chain: mainnet,
  transport: http(),
})

const { assetRegistry, usdc } = getAddresses(mainnet.id)

const amount = await getInitialDepositAmount(publicClient, {
  assetRegistry,
  asset: usdc,
})
```

Approving the factory before a spawn:

```ts
import { erc20Abi } from 'viem'
import { buildSpawnConduitCall, getAddresses, getInitialDepositAmount } from '@railnetorg/railnet-sdk'

const account = '0xd2135CfB216b74109775236E36d4b433F1DF507B'
const { assetRegistry, conduitFactory, usdc } = getAddresses(mainnet.id)

const amount = await getInitialDepositAmount(walletClient, { assetRegistry, asset: usdc })

await walletClient.writeContract({
  address: usdc,
  abi: erc20Abi,
  functionName: 'approve',
  args: [conduitFactory, amount],
  account,
})

const hash = await walletClient.writeContract({
  ...buildSpawnConduitCall({ factory: conduitFactory, /* ... */ }),
  account,
})
```

See [Deploying a multi-vehicle](/guides/deployingAMultiVehicle) for where this sits in the order.

## Returns

`bigint`

The initial deposit amount, in the asset's own decimals, and always non-zero, since the registry
refuses to authorize an asset without one. An asset it does not authorize reverts the read itself
with `AssetNotAuthorized`.

## Parameters

### assetRegistry

- **Type:** `Address`

The AssetRegistry contract address. Available as `assetRegistry` from [`getAddresses`](/contracts/getAddresses).

```ts
const amount = await getInitialDepositAmount(publicClient, {
  assetRegistry: '0xefdB0D96F9dce67b95200E9D9be46e0fA18b7042', // [!code focus]
  asset: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913',
})
```

### asset

- **Type:** `Address`

The underlying asset of the conduit or vehicle to spawn.

```ts
const amount = await getInitialDepositAmount(publicClient, {
  assetRegistry: '0x...',
  asset: '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913', // [!code focus]
})
```
