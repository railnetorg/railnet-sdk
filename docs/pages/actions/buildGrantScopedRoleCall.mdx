# buildGrantScopedRoleCall

Grants a scoped role on the ExternalAccessControl contract.

- Requires the role's admin role, held globally or scoped to `scope`. See [Managing roles](/guides/managingRoles#scoped-first).
- Reverts `PublicRoleAuthDenied` while the scoped role is public.
  [`buildSetScopedRolePublicCall`](/actions/buildSetScopedRolePublicCall) turns it off.

## Import

```ts twoslash
import { buildGrantScopedRoleCall } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, writeContract } from 'viem/actions'
import { buildGrantScopedRoleCall } from '@railnetorg/railnet-sdk'

const { request } = await simulateContract(client, {
  ...buildGrantScopedRoleCall({
    accessControl: '0x1234...',
    role: VEHICLE_STEAM_DEPOSIT,
    scope: '0x5678...',
    grantee: '0x9012...',
  }),
  account: '0xd2135CfB216b74109775236E36d4b433F1DF507B',
})

const hash = await writeContract(client, request)
```

Role constants are exported:

```ts twoslash
import { VEHICLE_STEAM_DEPOSIT, MULTI_VEHICLE_SET_QUEUES } from '@railnetorg/railnet-sdk'
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

### accessControl

### role

- **Type:** `Hex`

### scope

- **Type:** `Address`

### grantee
