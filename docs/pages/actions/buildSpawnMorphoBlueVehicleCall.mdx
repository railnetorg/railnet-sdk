# buildSpawnMorphoBlueVehicleCall

Deploys a vehicle that supplies into a single Morpho Blue market.

- The vehicle supplies the market's loan token; the market id decides the asset.
- Requires `FACTORY_SPAWN` on the factory's access control.
- [Deploying a vehicle](/guides/deployingAVehicle) gives the order.

## Import

```ts twoslash
import {
  buildSpawnMorphoBlueVehicleCall,
  getMorphoBlueSingleton,
  getMorphoMarketAsset,
} from '@railnetorg/railnet-sdk'
```

## Usage

Resolve both addresses, approve, then spawn:

```ts
import { erc20Abi } from 'viem'
import { simulateContract, writeContract } from 'viem/actions'
import {
  buildSpawnMorphoBlueVehicleCall,
  getAddresses,
  getInitialDepositAmount,
  getMorphoBlueSingleton,
  getMorphoMarketAsset,
  randomSalt,
} from '@railnetorg/railnet-sdk'
import { mainnet } from 'viem/chains'

const { assetRegistry, morphoBlueVehicleFactory } = getAddresses(mainnet.id)
const marketId = '0x3a85e619751152991742810df6ec69ce473daef99e28a64ab2340d7b7ccfee49'

const morpho = await getMorphoBlueSingleton(client, { factory: morphoBlueVehicleFactory })
const asset = await getMorphoMarketAsset(client, { morpho, marketId })
const amount = await getInitialDepositAmount(client, { assetRegistry, asset })

await writeContract(client, {
  address: asset,
  abi: erc20Abi,
  functionName: 'approve',
  args: [morphoBlueVehicleFactory, amount],
  account,
})

const { request } = await simulateContract(client, {
  ...buildSpawnMorphoBlueVehicleCall({
    factory: morphoBlueVehicleFactory,
    morpho,
    marketId,
    accessControl: '0x...',
    queryRegistry: '0x...',
    initialExpectedSupply: 10n ** 18n,
    querySalt: randomSalt(),
    deploymentSalt: randomSalt(),
  }),
  account,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

[`extractMorphoBlueVehicleAddress`](/utilities/receiptHelpers#extractmorphobluevehicleaddress) reads the deployed address from the receipt.

## Parameters

### factory

- **Type:** `Address`

The Morpho Blue vehicle factory. Available as `morphoBlueVehicleFactory` from [`getAddresses`](/contracts/getAddresses).

### morpho

- **Type:** `Address`

The Morpho Blue singleton. The spawn reverts `InvalidMorpho` unless it equals the factory
implementation's own immutable `MORPHO`.
[`getMorphoBlueSingleton`](#getmorphobluesingleton) reads it.

### marketId

- **Type:** `Hex`

32 bytes. Zero is rejected (`InvalidMarketId`), and a market the singleton does not know resolves
to a zero loan token, which fails as `InvalidAsset`. That loan token must also be authorized in the
AssetRegistry, or the spawn reverts `AssetNotAuthorized`.

### accessControl

- **Type:** `Address`

### queryRegistry

- **Type:** `Address`

### feeManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### modulesManager (optional)

- **Type:** `Address`
- **Default:** `zeroAddress`

### forbiddenAddresses (optional)

- **Type:** `Address[]`
- **Default:** `[]`

### initialExpectedSupply

- **Type:** `bigint`

Floor on the shares the seed deposit must mint. Zero is rejected
(`InvalidInitialExpectedSupply`), and a floor the deposit does not reach reverts
`ExpectedSupplyNotReached`.

### querySalt

- **Type:** `Hex`

### deploymentSalt

- **Type:** `Hex`

## getMorphoBlueSingleton

```ts
const morpho = await getMorphoBlueSingleton(client, { factory: morphoBlueVehicleFactory })
```

Reads the factory's `IMPLEMENTATION`, then that clone's `MORPHO`, the only singleton address this
factory accepts.

## getMorphoMarketAsset

```ts
const asset = await getMorphoMarketAsset(client, { morpho, marketId })
```

The market's loan token, the asset a supplier deposits and the token to approve.
