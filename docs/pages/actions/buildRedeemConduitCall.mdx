# buildRedeemConduitCall

Builds the `conduit.createRedeemFromConduitShares()` call.

- No approval. The conduit burns shares it already holds for `sender`.
- [`getRedeemConduitCall`](/actions/getRedeemConduitCall) reads the output asset for you.

## Import

```ts twoslash
import { buildRedeemConduitCall, randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
import { simulateContract, readContract, writeContract } from 'viem/actions'
import { conduitAbi, buildRedeemConduitCall, randomSalt } from '@railnetorg/railnet-sdk'

const conduit = '0xA0Cf798816D4b9b9866b5330EEa46a18382f251e'
const sender = '0xd2135CfB216b74109775236E36d4b433F1DF507B'

const asset = await readContract(client, {
  address: conduit,
  abi: conduitAbi,
  functionName: 'asset',
})

const { request } = await simulateContract(client, {
  ...buildRedeemConduitCall({
    conduit,
    shares: 1_000_000n,
    sender,
    outputAsset: { asset, value: 0n },
    salt: randomSalt(),
  }),
  account: sender,
})

const hash = await writeContract(client, request)
```

## Returns

A prepared call: `{ address, abi, functionName, args }`.

## Parameters

### conduit

- **Type:** `Address`

### shares

- **Type:** `bigint`

### sender

- **Type:** `Address`

The address that will send the transaction. The conduit derives the query salt from it. Through a
Safe, a batch or a relayer, that is the contract's address. See [The sender](/guides/depositingAndRedeeming#the-sender).

### outputAsset

- **Type:** [`Asset`](/types/Asset)

The asset to receive and a floor on its amount; `value: 0n` sets no floor. `conduit.asset()` is the
usual value.

### salt

- **Type:** `Hex`

A per-redeem salt. Use [`randomSalt`](/utilities/randomSalt).

### receiver

- **Type:** `Address`
- **Optional.** Defaults to `sender`.

Who receives the redeemed asset.
