# Roles

Role constants used for access control across the Railnet protocol. These are precomputed `keccak256` hashes that match the roles defined in the Solidity `Roles.sol` contract.

## Import

```ts
import { VEHICLE_STEAM, MULTI_VEHICLE_SET_QUEUES } from 'railnet-sdk'
```

## All Constants

### Factory

| Constant | Description |
| --- | --- |
| `FACTORY_SPAWN` | Permission to spawn new contracts via a factory |
| `FACTORY_SET_DEPRECATED` | Permission to deprecate a factory |

### Beacon

| Constant | Description |
| --- | --- |
| `BEACON_FREEZE` | Permission to freeze a beacon |
| `BEACON_PAUSE` | Permission to pause a beacon |
| `BEACON_UNPAUSE` | Permission to unpause a beacon |
| `BEACON_UPGRADE` | Permission to upgrade a beacon |

### Vehicle

| Constant | Description |
| --- | --- |
| `VEHICLE_STEAM` | Permission to call STEAM functions on a vehicle |
| `VEHICLE_SET_INTERCEPTIONS` | Permission to set interceptions |
| `VEHICLE_ALLOW` | Permission to allow operations on a vehicle |
