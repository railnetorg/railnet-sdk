# Receipt helpers

Reads back what a transaction produced, the addresses a spawn deployed and the queries a conduit
created.

## Import

```ts twoslash
import {
  extractAaveV3VehicleAddress,
  extractAccessControlAddress,
  extractConduitAddress,
  extractErc4626VehicleAddress,
  extractMorphoBlueVehicleAddress,
  extractMultiVehicleContracts,
  extractQueryIds,
  extractWrapperVehicleAddress,
} from '@railnetorg/railnet-sdk'
```

## Usage

After a spawn, read the address out of the receipt:

```ts
import { waitForTransactionReceipt, writeContract } from 'viem/actions'
import { extractConduitAddress } from '@railnetorg/railnet-sdk'

const hash = await writeContract(client, request)
const receipt = await waitForTransactionReceipt(client, { hash })

const conduit = extractConduitAddress(receipt, conduitFactory)
```

## extractConduitAddress

Extracts the deployed conduit address from a `buildSpawnConduitCall` transaction receipt.

```ts
const conduitAddress = extractConduitAddress(receipt, factoryAddress)
```

### Parameters

#### receipt
- **Type:** `TransactionReceipt`

#### factoryAddress
- **Type:** `Address`

### Returns

`Address | null`

The deployed conduit address, or `null` if not found.

## extractMultiVehicleContracts

Extracts the deployed MultiVehicle contract addresses from a `buildSpawnMultiVehicleCall` transaction receipt.

```ts
const contracts = extractMultiVehicleContracts(receipt, factoryAddress)
```

### Parameters

#### receipt
- **Type:** `TransactionReceipt`

#### factoryAddress
- **Type:** `Address`

### Returns

`MultiVehicleContracts | null`

The deployed MultiVehicle contract addresses, or `null` if not found.

#### MultiVehicleContracts

```ts
type MultiVehicleContracts = {
  multiVehicle: Address

  vehicleManager: Address
}
```

## extractWrapperVehicleAddress

Extracts the deployed vehicle address from a [`buildSpawnWrapperVehicleCall`](/actions/buildSpawnWrapperVehicleCall) transaction receipt.

```ts
const vehicleAddress = extractWrapperVehicleAddress(receipt, wrapperVehicleFactory)
```

Returns `Address | null`.

Every vehicle factory folds its deployment counter into the address, so a vehicle's address is only
known from the receipt.

## extractQueryIds

```ts
import { extractQueryIds } from '@railnetorg/railnet-sdk'

const created = extractQueryIds(receipt, conduit)
// [{ queryId: '0x...', receiver: '0x...' }]
```

The queries a transaction created on a conduit, in log order, from its `QueryCreated` events. Each
`queryId` is the key an indexer holds.

A deposit's id is known before the transaction is sent, from
[`getDepositConduitCall`](/actions/getDepositConduitCall) or
[`toQueryId`](/utilities/queryIdentity#toqueryid). A redeem's id is only known from the receipt. See
[`getRedeemConduitCall`](/actions/getRedeemConduitCall#returns).

Every helper here filters logs by their emitter first: a factory's transaction carries the logs of
everything it deployed, and several Railnet events share an argument name.
