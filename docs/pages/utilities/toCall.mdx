# toCall

`toCall` rewrites a built call's `address` field to `to`, the name EIP-5792's `sendCalls` expects.

## Import

```ts twoslash
import { toCall } from '@railnetorg/railnet-sdk'
```

## Usage

Batching the approval with the deposit is one confirmation for the user, on a wallet that supports
it:

```tsx
import { erc20Abi } from 'viem'
import { useSendCalls } from 'wagmi'
import { toCall } from '@railnetorg/railnet-sdk'

const { sendCalls } = useSendCalls()

sendCalls({
  calls: [
    { to: token, abi: erc20Abi, functionName: 'approve', args: [conduit, amount] },
    toCall(call),
  ],
})
```

## Before batching

**Atomicity is not guaranteed.** Whether a batch lands as one transaction depends on the wallet;
`getCapabilities` says.

**The effective sender.** A batch may execute from a smart account, which is then
`msg.sender`. A deposit built for the user's EOA reverts `InvalidQuerySalt`. See [The sender](/guides/depositingAndRedeeming#the-sender).
