# randomSalt

Returns a random `bytes32`, drawn from `crypto.getRandomValues`.

## Import

```ts twoslash
import { randomSalt } from '@railnetorg/railnet-sdk'
```

## Usage

```ts
const deploymentSalt = randomSalt()
```

## Returns

`Hex`

A deployment salt fixes a contract's address. A spawn that fails midway is retried against the same
address only with the same salt. A query salt lives for the whole operation. See [The salt](/guides/depositingAndRedeeming#the-salt).
